# The Latent Archive

Personal notes site for **Dhruva Myakeri** — parchment / dark-academia aesthetic, plain HTML + CSS + a little JS.

## Local preview

Open `index.html` in a browser, or from this folder:

```bash
npx serve .
```

Then visit the URL it prints (usually `http://localhost:3000`).

## Structure

```
index.html          Home
notes.html          All notes index
research.html       Research threads
about.html          About + contact
firm-jepa.html      Firm-State JEPA project record (shareable)
css/styles.css
assets/images/
```

## Adding a new note

1. Add a new HTML page at the root (e.g. `my-note.html`) or under `posts/`.
2. Link it from `index.html`, `notes.html`, and optionally `research.html`.
